# THE SILENT ARCHIVE — トップページ試作

このフォルダで次を実行し、ブラウザで http://127.0.0.1:4174/ を開いてください。

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

配信用ライブラリは `vendor/` に同梱しているため、閲覧だけなら `npm install` は不要です。ライブラリの出典は [LIBRARIES.md](LIBRARIES.md) を参照。

終了はターミナルで `Ctrl+C`。WebGL 2対応ブラウザを推奨します。下スクロールで視点が空間内の下方へ移動し、上スクロールで上方へ戻ります。ポインタを動かすと周辺に観測用の光が現れます。右上の設定から描画品質と動きの軽減を選べます。謎解き要素はこの試作に含めていません。

空間には操作対象が隠されており、観測光を重ねると姿と光点が現れます。光点にポインタを重ねると「移動」または「資料閲覧」が表示されます。Tabキーでも対象を選択できます。移動先と資料は動作確認用の試作です。

この試作はWebGL 2のシェーダーで漂う構造物と移動先の惑星を描画しています。高品質設定は描画解像度の切替です。展示室および正式な遺物はまだ制作していません。
